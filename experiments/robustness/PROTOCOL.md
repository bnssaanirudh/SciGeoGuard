# Robustness evaluation protocol

Existing v11 metamorphic families cover selected author-controlled mutations. Expand with cases for contradictory or missing metadata, CRS/resolution conflicts, spectral substitution, temporal aggregation, vertical datums, provenance loss, uncertainty failures, conflicting intent, and multi-fault combinations.

For each family record: frozen case ID, fault(s), expected label source, applicable systems, generated/reference vs expert label status, per-class recall, false certification, abstention, diagnostic coverage, and repair outcome. Keep a family-level split and report family-clustered intervals. Do not count multiple variants from one template as independent observations. Use separate datasets for rule development and final evaluation.

The current branch contains protocol guidance only; it does not manufacture robustness labels or claim new robustness results.
