# Repair evaluation protocol

Separate five outcomes: (1) fault detection, (2) proposal coverage, (3) independent scientific correctness, (4) edit cost/refusal, and (5) same-verifier re-verification. Preserve all generated proposals, including incorrect and rejected proposals. Independent reviewers must assess whether an edit is scientifically justified and whether it introduces side effects. Analyze one-edit and multi-edit cases separately, and categorize no-repair outcomes (no candidate, budget, evidence missing, conflicting findings, or unsafe action).

Current v11 results cover repair proposal and same-verifier re-verification only. The provided `reports/reproduction_20261016/per_case.csv` and original certificate outputs support case-level failure triage. Independent correctness remains pending.
