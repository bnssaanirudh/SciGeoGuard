# SciGeoGuard-X v1.0.0 release notes

This public package freezes the evidence used after the v9.1 final merge.

## Included
- complete experiment notebooks from v2 through v9.1;
- historical output directories for v2/v3/v5/v5.2/v6/v8/v8.1;
- pending v7 reviewer materials without false human metrics;
- successful v8.2/v9 IMERG recovery outputs;
- canonical v9.1 frozen evidence, final regional result tables, composite figure, caption, and manuscript-ready result paragraph.

## Excluded intentionally
- obsolete v9 figure/status generated when earlier evidence files were missing from that runtime;
- empty/generated v7 final human metrics;
- local model caches and third-party source rasters.
