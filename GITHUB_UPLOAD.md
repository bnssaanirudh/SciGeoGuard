# What to upload to GitHub

Upload the **contents of this repository root**, not the outer ZIP as a single file.

Recommended repository name: `SciGeoGuard-X`.

After creating the repository:
1. extract `SciGeoGuard-X_GitHub_FINAL_Upload.zip`;
2. open the extracted `SciGeoGuard-X` folder;
3. upload/commit everything inside it;
4. keep the repository public for the Code & Data submission;
5. create a release tag such as `v1.0.0`;
6. if desired, connect the GitHub release to Zenodo to obtain an archival DOI.

Before publishing, confirm the Apache-2.0 licensing choice is compatible with your institutional/IP obligations.
