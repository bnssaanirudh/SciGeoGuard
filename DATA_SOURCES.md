# External Earth-observation data sources

The repository does **not** redistribute full third-party Earth-observation datasets. The notebooks retrieve or reference public source products.

- **Sentinel-2 L2A** — ESA / Copernicus; live spectral-role counterfactuals.
- **ESA WorldCover 2021 v200** — categorical land-cover resampling tests.
- **GPM IMERG Final V07** — half-hourly precipitation-rate semantics.
- **Copernicus DEM GLO-30** — DSM provenance/resolution tests.

Users are responsible for following the original providers' access, attribution, and licensing terms. The CSV/JSON files in `results/` are derived experiment outputs and metadata summaries, not redistributions of the full source products.
